# Modelo do perfil do candidato
NÃO ponhas o teu perfil real neste ficheiro se o repositório for público.
Guarda o texto real no segredo CANDIDATE_PROFILE (Settings → Secrets and variables → Actions).

Nome, cargo atual e empresa, anos de experiência, formação, línguas (e as que NÃO falas),
áreas-alvo, geografia, salário mínimo, quando vale a pena sair do emprego atual.
